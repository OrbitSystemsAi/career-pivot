# Pitch Deck

The deck itself is built and maintained in Google Slides/Canva (external). This
folder holds everything that supports it locally.

- `assets/` — logos, screenshots, product images, charts used in slides
- `research/` — market sizing, competitor data, sources backing up claims in the deck
- `notes/` — outline, speaker notes, talking points, version history
- `exports/` — exported PDF/PNG snapshots of the deck (e.g. for archiving before investor meetings, or for offline review)
